Goal: Master SVD, one of the most powerful matrix factorizations in ML.

Practice Projects

Image Compression with SVD: Use SVD to compress an image by keeping only the top k singular values. Show reconstructions with k = 5, 20, 50, 100 and compare file sizes.
Recommender System with SVD: Implement a basic movie recommender system using SVD on a user-item rating matrix (use MovieLens or create synthetic data).

Key Concepts to Master

SVD decomposition: U, Σ, V^T
Singular values vs eigenvalues
Low-rank approximation
Applications: compression, denoising, collaborative filtering
