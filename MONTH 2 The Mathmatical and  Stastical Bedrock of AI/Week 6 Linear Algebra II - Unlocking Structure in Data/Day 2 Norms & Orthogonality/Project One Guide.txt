A comprehensive solution for checking orthogonality and visualizing orthogonal vs non-orthogonal vectors.
Features:

check_orthogonality() Function:

Checks all pairs of column vectors using dot products
Determines if vectors are orthogonal (dot product ≈ 0)
Checks if vectors are unit vectors (orthonormal)
Provides detailed output with checkmarks


2D Visualization (visualize_2d_vectors()):

Shows vectors as arrows from origin
Displays angles between vectors
Color-coded with labels
Perfect for understanding perpendicular relationships


3D Visualization (visualize_3d_vectors()):

Interactive 3D vector display
Shows spatial relationships
Useful for understanding orthogonal bases


Five Complete Examples:

Orthogonal 2D vectors (90° angle)
Non-orthogonal 2D vectors (45° angle)
Orthonormal 3D vectors (standard basis)
Orthogonal but not orthonormal 3D
Non-orthogonal 3D vectors



Key Concepts Demonstrated:

Orthogonal: Dot product = 0, angle = 90°
Orthonormal: Orthogonal + unit length (magnitude = 1)
Visual representation of angles between vectors
Practical applications in linear algebra
