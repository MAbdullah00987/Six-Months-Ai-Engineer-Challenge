## 📊 Common Tasks

### 1. Load and Prepare Data

```python

import pandas as pd

# Load data

# Preprocess

X, y = preprocessor.prepare_features(df, target_column='Salary')

# Split
```

### 2. Train Model with Custom Parameters

```python

    learning_rate=0.01,      # Step size
    n_iterations=2000,       # Max iterations
    tolerance=1e-6,          # Convergence threshold
    regularization='l2',     # 'l1', 'l2', or None
    lambda_reg=0.1          # Regularization strength
)

model.fit(X_train, y_train, verbose=True)
```

## 🎯 Hyperparameter Tuning

### Learning Rate Selection
```python
# Too small: slow convergence
model = LinearRegressionScratch(learning_rate=0.001)

# Good balance
model = LinearRegressionScratch(learning_rate=0.01)

# Too large: may not converge
model = LinearRegressionScratch(learning_rate=1.0)
```

### Regularization Strength
```python
# No regularization
model = LinearRegressionScratch()

# Light regularization
model = LinearRegressionScratch(regularization='l2', lambda_reg=0.01)

# Strong regularization
model = LinearRegressionScratch(regularization='l2', lambda_reg=10.0)
```

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| Model not converging | Reduce learning rate |
| Training too slow | Increase learning rate, reduce iterations |
| Poor test performance | Add regularization, check for overfitting |
| NaN values in weights | Reduce learning rate, check data scaling |
| Negative R² | Model worse than baseline, retrain |

## 🔍 Evaluation Metrics

### Regression Metrics
- **MSE**: Mean Squared Error (lower is better)
- **RMSE**: Root Mean Squared Error (same units as target)
- **MAE**: Mean Absolute Error (robust to outliers)
- **R²**: Coefficient of determination (0 to 1, higher is better)

### Interpretation
- **R² = 1.0**: Perfect fit
- **R² = 0.8-0.9**: Very good fit
- **R² = 0.6-0.8**: Good fit
- **R² < 0.5**: Poor fit
- **R² < 0**: Model worse than predicting mean

### Key Concepts
1. **Gradient Descent**: Iterative optimization algorithm
2. **Cost Function**: Measures model error (MSE)
3. **Learning Rate**: Step size for weight updates
4. **Regularization**: Prevents overfitting
5. **Feature Scaling**: Normalizes input features

### Mathematical Formulas

**Cost Function (MSE)**:
```
J(θ) = (1/2m) Σ(h(x^(i)) - y^(i))²
```

**Gradient Update**:
```
θ_j := θ_j - α × (1/m) × Σ(h(x^(i)) - y^(i)) × x_j^(i)
```

**R² Score**:
```
R² = 1 - (SS_res / SS_tot)
```
